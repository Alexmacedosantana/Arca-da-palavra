# 📖 Arca da Palavra

Projeto web cristão desenvolvido com o objetivo de compartilhar **esboços bíblicos, estudos e reflexões**, de forma simples, visual e acessível para todos os dispositivos.

🔗 **Acesse o site:**  
https://alexmacedosantana.github.io/Arca-da-palavra/

✨ Funcionalidades

- 📱 Layout **responsivo** (desktop, tablet e mobile)
- 📜 Conteúdo bíblico organizado em caixas
- ⬆️ Botão **Voltar ao Topo** estilo WhatsApp
- 🎨 Estilo visual limpo e focado na leitura
- ⚡ Animações suaves com CSS
- 🌐 Publicado com **GitHub Pages**


## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3 (Flexbox e Media Queries)  
- JavaScript (interações simples)  
- GitHub Pages (deploy)
